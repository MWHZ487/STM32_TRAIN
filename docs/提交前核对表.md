## 二、代码要点 ↔ 预期现象（录像时对照）

### 01light（任务 2.1 输出点灯）
- 代码：`USER CODE 3` 里 `WritePin(RESET)` → `HAL_Delay(520)` → `WritePin(SET)` → `HAL_Delay(520)`
- PC13 低电平点亮，所以：**RESET = 亮，SET = 灭**
- 预期：亮 520 ms、灭 520 ms，一个完整周期约 1.04 s

### 02switch（任务 2.2 轮询按键 + 软件消抖）
- 代码：主循环读 PA0 → `HAL_Delay(20)` → 再读 → `TogglePin` → `while (读到低) 等松手` → `HAL_Delay(20)`
- 预期：
  - 按一下 → 翻转一次并保持
  - 按住不放 → 只翻一次
  - 连按 10 次 → 翻 10 次
- 说明：轮询期间 CPU 被 `HAL_Delay` 和 `while` 占住（这是与 2.3 对照的关键）

### 03switch2（任务 2.3 外部中断 + 时间窗消抖）
- 配置：PA0 → `GPIO_EXTI0`，**下降沿**，内部上拉；NVIC 使能 `EXTI line0 interrupt`
- 代码：
  - 回调：`g_time_ms = HAL_GetTick(); g_key_event = 1;`（只置标志，无延时）
  - 主循环：`if (g_key_event) { g_key_event = 0; if (now - last_accept_ms > 50) { 记时刻并翻转 } }`
- 预期：
  - 按一下 → 翻转一次并保持
  - 按住 3 秒 → 只翻一次（边沿触发）
  - 慢速连按 10 次 → 翻 10 次

## 四、已经修复并记录的问题（可写进 README）

1. **CubeMX `SYS → Debug = No Debug`** 会生成 `__HAL_AFIO_REMAP_SWJ_DISABLE()`，
   固件启动后关闭 SWD，导致「烧录一次后无法连接（No device found on target）」。
   修复：三个工程 `.ioc` 均改为 `Serial Wire`，生成代码变为 `__HAL_AFIO_REMAP_SWJ_NOJTAG()`（保留 SWD）。
2. 误把板载 `R` 复位键当输入按键，现象是「按一下灯闪一下」（其实是复位初始化瞬态）。
3. 按键接触不良/误接 3.3V，曾导致「按下无反应」「按一次翻两次」。
4. 消抖方案：先试时间窗，抖动严重时改为「状态机 + 松开确认」，最终 03switch2 采用 50 ms 时间窗。
5. 调试手段：用 SWD **hotplug** 直接读取 RAM 里的计数器（`edge_count` / `accept_count`），
   不打断运行即可定位「中断触发次数 vs 实际翻转次数」。
