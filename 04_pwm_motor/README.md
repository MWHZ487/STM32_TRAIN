# 02 · PWM 控制电机不同速度正反转

**任务**：用两路 PWM（TIM3 CH1/CH2）驱动电机驱动模块，演示「正转渐快 → 停 → 固定转速 → 反转渐快 → 停」的循环。
**芯片**：STM32F103C8T6　**电机**：MC520P30-12V 直流减速电机（12 V）

## 一、接线

| STM32 引脚 | 接到电机驱动模块 | 说明 |
| --- | --- | --- |
| **PA6**（TIM3_CH1） | AIN1 / IN1 | 正转时输出 PWM，反转时输出 0 |
| **PA7**（TIM3_CH2） | AIN2 / IN2 | 反转时输出 PWM，正转时输出 0 |
| **PA3** | nSLEEP / STBY | 高电平使能驱动（代码里初始化为 **高**） |
| 5V 或 3V3 | 驱动模块 VCC（逻辑电源） | 按模块要求 |
| **GND** | 驱动模块 GND **+ 12 V 电源负极** | 三处必须共地 |
| — | 驱动模块 VM ← **12 V 电源正极** | 电机功率电源，不能只靠 ST-Link 的 3.3 V |
| — | 驱动模块 OUT1/OUT2 → 电机两根线 | 转向由 AIN1/AIN2 决定，交换 OUT 线会反 |

> 方向逻辑（本工程）：
> - 正转：`AIN1 = PWM`、`AIN2 = 0`
> - 反转：`AIN1 = 0`、`AIN2 = PWM`
> - 停：两路都 0（自由滑行，不是刹车）

## 二、参数

| 项 | 值 | 计算 |
| --- | --- | --- |
| PWM 频率 | **2 kHz** | 72 MHz ÷ (35+1) ÷ (999+1) = 2 kHz |
| 占空比范围 | 50% → 95% | CCR 500…950 / 1000；低于约 50% 电机可能不转（死区） |
| 固定转速段 | 70% | CCR = 700，保持 2 s |
| 一个完整演示周期 | **8.5 s** | 正转渐快 2 s + 停 1 s + 70% 2 s + 反转渐快 2 s + 停 1.5 s |

## 四、代码结构

```text
Core/Src/main.c
├── MX_GPIO_Init()        // PA3 = nSLEEP，推挽输出，初始高电平（使能驱动）
├── MX_TIM3_Init()        // PSC=35, ARR=999；CH1/CH2 均为 PWM1 模式
├── HAL_TIM_PWM_Start()   // 同时启动 CH1 与 CH2
└── while (1)
    ├── 正转渐快：CCR1 = 500→950，每档 200 ms，CCR2 = 0
    ├── 停 1 s：两路 0
    ├── 固定 70%：CCR1 = 700，保持 2 s
    ├── 反转渐快：CCR2 = 500→950，每档 200 ms，CCR1 = 0
    └── 停 1.5 s
```

## 五、现象（验收）

- 电机先**正向加速**（能明显听出/看出转速从慢到快），停 1 s；
- 再以固定 70% 转速转 2 s；
- 然后**反向加速** 2 s，最后停 1.5 s，循环。
- 现象视频：本目录 `现象_演示视频.mp4`（17.9 s，覆盖约 2 个完整周期）。

## 六、排错

| 现象 | 先查什么 |
| --- | --- |
| 电机完全不动 | **VM 12 V 是否接上**、共地是否三处都接、nSLEEP（PA3）是否高 |
| 只朝一个方向转 | AIN1/AIN2 是否分别接到 PA6/PA7；代码里反转段是否执行到 |
| 低速段不转 | 占空比太低（<50%）在电机死区内，属正常；提高起点 CCR |
| 转速忽快忽慢 / 复位 | 12 V 电源带不动，或共地不良；给电机电源并联合适电容 |
| 想换成刹车而不是滑行 | 停转时让两路都输出高电平（短接电机），而不是都写 0 |
