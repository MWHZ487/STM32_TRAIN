# 一、机试预测题（6 套）

## 【题 1】串口 DMA 回显 + OLED 计数 · 25 分钟

**题目**
上位机通过串口发送任意长度字符串，单片机收到后：
① 原样回发（回显）
② 在 OLED 上显示"已接收帧数"和"最近一帧长度"

**考察点**
- `HAL_UART_Transmit_DMA` 非阻塞发送
- `HAL_UARTEx_ReceiveToIdle_DMA` + IDLE 判断帧结束
- 回调里重新挂接收（`HAL_UARTEx_RxEventCallback`）
- OLED 数字显示

**实现步骤**
```text
1. CubeMX：USART1 异步 115200，加 DMA(USART1_TX)，开 USART1 全局中断
2. I2C1 + PB6/PB7 接 OLED
3. BSP_UART_Init(&huart1)   → 启动 IDLE+DMA 接收
4. 主循环：读帧 → 回发 → 帧数++ → OLED 刷新
5. 回调 HAL_UARTEx_RxEventCallback：记录长度、置标志、重新挂接收
```

**评分要点**
```text
□ 用的是 DMA 而不是 HAL_UART_Transmit（阻塞）
□ 回调里重新挂接收（漏了只能收一帧）
□ 不定长帧用 IDLE 判断，不是写死长度
□ 主循环不阻塞，OLED 刷新不影响接收
```

## 【题 2】按键中断 + PWM 三档亮度 · 30 分钟

**题目**
3 个按键（K1/K2/K3）分别设定 LED 亮度 30% / 60% / 100%，OLED 同步显示当前档位。

**考察点**
- 3 个 GPIO_EXTIx 下降沿中断
- EXTI 回调里区分 GPIO_Pin
- 消抖（时间窗 50ms）
- TIM PWM 输出 + `__HAL_TIM_SET_COMPARE`

**实现步骤**
```text
1. PB0/PB1/PB5 → GPIO_EXTIx，下降沿，Pull-up；NVIC 使能对应 EXTI line
2. TIM3 CH1（PA6）→ PWM，PSC=71 ARR=999 → 1kHz
3. HAL_TIM_PWM_Start
4. 回调：判断是哪个 Pin → 时间窗消抖 → 置事件标志
5. 主循环：取事件 → 算 CCR → SetCompare → OLED 显示百分比
```

**评分要点**
```text
□ 中断里只置标志，不做业务（不延时、不刷屏）
□ 三个按键在同一个回调里用 GPIO_Pin 区分
□ 有消抖，不是按一次变好几次
□ CCR 用比例算，不是硬编码三个魔数
```

## 【题 3】编码器测速 + 串口上报 · 30 分钟

**题目**
用编码器测电机转速，每 100ms 通过串口以 `RPM` 形式上报一次，静止时输出 0。

**考察点**
- TIM 编码器模式（TI1 and TI2，×4 倍频）
- `(int16_t)` 处理 16 位计数回绕
- 定时中断里按周期采样
- `RPM = delta × 60 / (PPR × T)`

**实现步骤**
```text
1. TIM2 → Encoder Mode，PSC=0，ARR=65535，TI1 and TI2
   PA0/PA1 → GPIO **Pull-up**（漏了会读出假脉冲）
2. TIM1 → 10ms 定时中断（PSC=7199, ARR=99）
3. 中断里：读 CNT → 强转 int16_t → 相减得 delta → 算 RPM
4. 主循环：每 100ms printf 一次
```

**关键代码**
```c
int16_t now   = (int16_t)__HAL_TIM_GET_COUNTER(&htim2);
int16_t delta = now - last;
last = now;
float rpm = (float)delta * 60.0f / (PPR * 0.01f);
```

**评分要点**
```text
□ HAL_TIM_Encoder_Start(&htim2, TIM_CHANNEL_ALL)  ← 必须 ALL
□ 计数差值用 int16_t，不用 int32_t 直接减
□ 采样周期和控制周期对齐，不是随手 HAL_Delay
□ PPR 说得出怎么来的（线数 × 4 × 减速比）
```

## 【题 4】PID 定速 · 35 分钟

**题目**
电机稳定运行在 200 RPM。K1 切到 300 RPM，K2 切到 100 RPM，OLED 显示目标与实际。
（机试不一定真接电机，可要求"代码写完 + 说清怎么验证"）

**考察点**
- PID 三项 + 双重限幅
- 输出映射到 PWM（含死区补偿）
- 串级结构：速度环是内环
- 控制周期固定

**实现步骤**
```text
1. PID 结构体：Kp/Ki/Kd、e_last、integral、out_max、i_max
2. 10ms 中断：测速 → PID_Calc → MOTOR_Set
3. 输出映射：ccr = DEAD + |u|，方向靠换通道
4. 按键切目标，切目标时清积分
```

**评分要点**
```text
□ 结构体用 float 存 Kp/Ki/Kd（uint16 存不了 0.5）
□ 有 integral 累加 + 积分限幅
□ 有 out_max 输出限幅
□ 两个通道每次都写，没写的那个要清 0
□ 不往 CCR 塞负数
```

## 【题 5】PID 定位置 · 35 分钟

**题目**
按一次键，电机正转 3 整圈后停住；OLED 显示当前累计脉冲与目标脉冲。

**考察点**
- 编码器累计位置
- 串级：位置环（外）+ 速度环（内）
- 到位判断 + 死区

**实现步骤**
```text
1. position += delta（不清零才是位置）
2. 目标位置 = 3 × PPR
3. 位置环：PID 输出"目标速度"，再限速 → 交给速度环
4. |target - position| < 阈值 停止
```

**关键代码**
```c
float rpm_target = PID_Calc(&pos, target_pulse, now_pulse);
if (rpm_target >  300) rpm_target =  300;
if (rpm_target < -300) rpm_target = -300;
float u = PID_Calc(&spd, rpm_target, rpm);
```

**评分要点**
```text
□ 位置环和速度环是两个独立的 PID 结构体
□ 外层输出限速，否则位置误差大时给出不可能达到的转速
□ 位置用 int32_t 累计（防溢出）
```

# 二、面试预测题（30 题，按模块分组）

> 面试只占 20%，且明确说不深。**答出关键词就够了，不用长篇大论。**

## A. C 语言基础（5 题）

**A1. 结构体和 typedef 是什么关系？**
结构体是类型定义，`typedef` 给它起个别名，这样就不用每次写 `struct xxx`。

**A2. 为什么函数参数有时候要传指针？**
要在函数里改调用方的数据（比如 PID 的 `integral`、`e_last` 必须跨调用保留，传值就是改副本）。

**A3. `static` 修饰局部变量是什么意思？**
变量存在静态区，只初始化一次，函数返回后值还在（比如记录上一次的计数）。

**A4. `int8_t` / `int16_t` / `int32_t` 有什么区别？**
位宽不同，表示范围不同。`int16_t` 是 -32768~32767，`uint32_t` 是 0~4294967295。**选类型时要看数据会不会是负数、会不会超范围。**

**A5. `#define` 和 `const` 的区别？**
`#define` 是预处理文本替换，没有类型；`const` 是真正的变量，有类型、能调试。

---

## B. 串口与 DMA（5 题）

**B1. 串口为什么用 DMA？**
`HAL_UART_Transmit` 是阻塞的，发送期间 CPU 只能等。DMA 让 CPU 只负责把数据放进缓冲，搬运由 DMA 完成，CPU 立刻回去做别的事。

**B2. 怎么接收不定长的串口帧？**
DMA 一直收 + 用 **IDLE 中断**判断"总线空闲=这一帧结束"，回调里拿到本帧长度。（`HAL_UARTEx_ReceiveToIdle_DMA` + `HAL_UARTEx_RxEventCallback`）

**B3. 接收回调里为什么必须重新启动接收？**
HAL 的接收是单次的，一次完成后状态机回到 READY，不重新挂就只能收一帧。

**B4. 115200 8N1 一秒能发多少字节？**
一帧 10 位（1 起始 + 8 数据 + 1 停止），115200 / 10 ≈ **11520 字节/秒**。

**B5. `printf` 是怎么把数据发到串口的？**
`printf` 内部最终调用 `_write()`，重定向 `_write` 到 `HAL_UART_Transmit` 就行。

---

## C. I2C 与 OLED（3 题）

**C1. I2C 为什么需要上拉电阻？**
I2C 是**开漏**输出，只能主动拉低，靠上拉电阻把线拉高，才能产生完整的高低电平。

**C2. OLED（SSD1306）0x3C 和 0x78 什么关系？**
`0x3C` 是 7 位地址，HAL 接口要传 8 位地址（左移一位）：`0x3C << 1 = 0x78`。

**C3. OLED 的"页"是什么？**
SSD1306 显存按页组织，128×64 分 8 页，每页 8 行像素，一列一字节。所以 `y` 是页号（0~7），不是像素行。

---

## D. PWM 与电机（5 题）

**D1. PWM 频率怎么算的？**
`f = 定时器时钟 / (PSC+1) / (ARR+1)`。72MHz、PSC=71、ARR=999 → 1kHz。

**D2. 为什么 APB1 是 36MHz，定时器却是 72MHz？**
APB1 分频系数不为 1 时，定时器时钟会自动 ×2。所以 TIM2/3/4 的输入仍是 72MHz。

**D3. 怎么用两路 PWM 控制正反转？**
H 桥的两个输入脚各接一路 PWM：
```text
AIN1 = PWM, AIN2 = 0  → 正转
AIN1 = 0,   AIN2 = PWM → 反转
两路都 0              → 刹车（H 桥短接）
```

**D4. 为什么不能往 CCR 里写负数？**
CCR 是 16 位无符号寄存器，写 -500 会变成 65036，大于 ARR → 输出恒为 100% 占空比。**负数必须取绝对值，方向靠换通道。**

**D5. 什么是死区补偿？**
电机占空比低于某个值不转（静摩擦）。死区补偿就是给输出加一个偏置：`ccr = DEAD + |u|`，把 PID 输出的原点挪到电机真正起转的点。

---

## E. 编码器与 PID（7 题）

**E1. 编码器模式比用外部中断数脉冲好在哪？**
硬件自动判方向、自动倍频（×2/×4），CPU 零开销；外部中断在高转速下中断率极高还会丢脉冲。

**E2. 计数差值为什么要 `(int16_t)` 强转？**
16 位计数器会从 65535 溢出回 0。直接减得 -65525（错），强转成 int16_t 后按补码解释：`5 - (-6) = 11`（对）。

**E3. PPR 是什么？**
每转脉冲数。`PPR = 编码器线数 × 4（四倍频）× 减速比`。

**E4. 为什么只有 P 会有稳态误差？**
P 的输出正比于误差，要维持一定输出就必须保留一个非零误差。I 项把误差**累加**起来，误差归零后 integral 还留着，输出就稳住了。

**E5. 为什么积分要限幅？**
误差长期存在时（堵转、大阶跃）integral 会累到几万，等误差消失后输出还顶着不松，造成大超调甚至振荡。这叫**积分饱和**。

**E6. 输出限幅和积分限幅分别防什么？**
`out_max` 防 PWM 越界（CCR 有上限）；`i_max` 防积分饱和。**两个都要有。**

**E7. 位置环为什么外面套速度环？**
位置环输出"该用多快冲过去"，速度环负责让电机真的达到那个速度。直接拿位置误差驱动 PWM 响应很猛、容易超调。这叫**串级控制**。

## F. 项目与调试（5 题）

**F1. 你怎么判断是软件问题还是硬件问题？**
用 SWD 直接读寄存器：读 `TIMx->CCR` 看有没有输出、读 `GPIOx->IDR` 看电平、读 `CFSR/HFSR` 看有没有 HardFault。寄存器对就查硬件，不对就查代码。

**F2. 电机转得慢，你怎么排查？**
先分三种可能：占空比不够 / 机械堵转 / 供电塌陷。量 `VIN` 带载电压、量 `OUT1/OUT2`、断电手转输出轴。**不能直接加大占空比**——堵转时加大就是烧电机。

**F3. PID 一上电就飞车，什么原因？**
PWM 方向和编码器计数方向相反 → 变正反馈。开环验方向：给固定 PWM 看 RPM 是正是负，反了就对调 A/B 相。

**F4. 这个项目你印象最深的 bug 是什么？**
（选一个真实经历讲）例：电源开关没打开，`VIN` 只有 2.2V，一直误以为是电池内阻和驱动芯片的问题，最后发现是根本没通。

**F5. 如果给你两天做定位置，你怎么安排？**
先把编码器位置累加验通 → 位置环只用 P → 限速 → 到位判断加阈值 → 再考虑串级优化。

```text
【架构】bsp(硬件) / pid(算法) / app(业务) / main(调度)
        中断里只做 采样→计算→输出，不 printf 不延时

【串口】DMA 发送不阻塞；接收用 DMA+IDLE 判帧尾；
        回调里必须重新挂接收；115200 ≈ 11520 字节/秒

          PPR = 线数×4×减速比；PA0/PA1 要上拉

       两路 PWM 定方向；CCR 无符号，绝不写负数；
       两个通道每次都要写

【PID】u = Kp·e + Ki·Σe + Kd·Δe
       传指针（状态要跨调用）；integral 和 out 都要限幅
       只有 P 有稳态误差；I 消除；D 放大噪声（速度环一般 0）
       偏差大时清积分；切工况清积分

【位置环】position += delta；外层限速；两套 PID 结构体

【死区】ccr = DEAD + |u|；DEAD 要接近实测值，压线会抖

【排查】先查有没有通，再查够不够；先硬件后软件；用寄存器验证
```
