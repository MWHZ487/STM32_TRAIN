## 卡 1 · 定义一个跨函数用的变量

**我要做**：这个变量中断里要用、主循环也要用

```c
/* 放在 USER CODE BEGIN PV */
static int16_t  g_last_cnt = 0;      /* 名字前的 g_ 表示 global */
static float    g_speed    = 0.0f;
static volatile uint8_t g_flag = 0;  /* 中断和主循环共享的，加 volatile */
```

**记住**：

```text
局部变量  →  写在函数里面，函数返回就没了
全局变量  →  写在函数外面，所有函数都能用
static    →  只在本文件可见（好习惯，防止重名）
volatile  →  中断会改的变量必须加
```

## 卡 2 · 定义一个结构体 + 定义变量 + 初始化

**我要做**：把一堆相关的数打包成一个东西

```c
/* USER CODE BEGIN PTD —— 类型定义放这里 */
typedef struct {
  float Kp, Ki, Kd;
  float e_last;
  float integral;
} PID_USE;

/* USER CODE BEGIN PV —— 变量定义放这里 */
static PID_USE PID = {
  .Kp = 0.5f, .Ki = 0.03f, .Kd = 0.0f,
  .e_last = 0.0f, .integral = 0.0f,
};
```

**使用成员**：

```c
PID.Kp = 1.0f;          /* 普通变量用 . */
p->Kp  = 1.0f;          /* 指针用 -> */
```

**易错**：`PID_USE` 是**类型名**，不能写 `PID_USE.Kp`；要用**变量名** `PID.Kp`。

## 卡 3 · 限幅（把值夹在上下限之间）

**我要做**：值不能超过 ±450

```c
if (u >  450) u =  450;
if (u < -450) u = -450;
```

**或写成一行**：

```c
if (u > 450) u = 450;
```

**易错**：`if` 后面没分号，别写成 `if (u > 450) u = 450;` 之外再加东西。

## 卡 4 · 取绝对值

**我要做**：不管正负，只要大小

```c
int32_t ccr = DEAD + (u >= 0 ? u : -u);     /* 三元 */
```

**或**：

```c
int32_t a = u;
if (a < 0) a = -a;
```

**为什么不用 `abs()`**：`abs` 是给 `int` 的，`float` 要用 `fabsf`。手写最省事。

## 卡 5 · 按时间分档（阶跃）

**我要做**：0~4 秒给 100，4~8 秒给 200，8~12 秒给 300

```c
if      (s <  4.0f) v = 100.0f;
else if (s <  8.0f) v = 200.0f;
else if (s < 12.0f) v = 300.0f;
else                v = 100.0f;
```

**易错**：`if` 和 `else if` 的条件是**累进**的，`s < 8` 那行意味着 `s >= 4 且 s < 8`。

## 卡 7 · 取余做循环

**我要做**：每 16 秒从头开始

```c
int32_t tick = g_tick % 1600;     /* g_tick 一直涨，取余后 0~1599 循环 */
float   s    = tick * 0.01f;      /* 变成 0~16 秒 */
```

**记住**：`a % b` 的结果永远在 `0 ~ b-1`。

```text
1600 个 10ms = 16 秒  →  % 1600
1200 个 10ms = 12 秒  →  % 1200
```

## 卡 8 · 中断里"置标志"，主循环"消费"

**我要做**：中断算出结果，主循环负责发出去

```c
/* PV */
static volatile uint8_t g_new_sample = 0;

/* 中断最后 */
g_new_sample = 1;

/* 主循环 */
while (1)
{
  if (g_new_sample)
  {
    BUFFER_Send();        /* 函数内部会把它清 0 */
  }
}
```

**为什么这样做**：中断里不要做耗时的事（发送、刷屏），只置标志。

## 卡 9 · 函数传指针改外部变量

**我要做**：函数里算完，把结果留在外面的结构体里

```c
void PID_Calc(PID_USE *p, float target, float actual);

/* 里面 */
p->integral += e;          /* 直接改外面的数据 */

/* 调用 */
PID_Calc(&PID, 200.0f, rpm);    /* 传地址要用 & */
```

**记住**：

```text
要改外面的值  →  传指针（加 *），调用时加 &
只读不改     →  传值
```

## 卡 15 · 差值和累计

**我要做**：算这 10ms 转了多少，顺便累计位置

```c
int16_t now   = (int16_t)__HAL_TIM_GET_COUNTER(&htim2);
int16_t delta = now - g_last_cnt;
g_last_cnt = now;                 /* ← 必须更新，下次要用 */

g_position += delta;              /* 累计位置 */
float rpm = (float)delta * 60.0f / (PPR * 0.01f);
```

**三件套顺序不能乱**：

```text
① 读当前值
② 减去上次值 → 得到增量
③ 更新上次值 = 当前值
```
